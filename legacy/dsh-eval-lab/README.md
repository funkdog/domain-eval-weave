# dsh-eval-lab compatibility package

This private workspace preserves the historical DSH runtime, package layout and replay contracts used before
DomainEval Weave became the public product. New Capsule and Evaluator work belongs in `packages/weave`.

The compatibility package is tested and packed by the root workspace but is not published as the public
DomainEval Weave package. Its Capsule example and license are frozen compatibility snapshots; contract tests
keep them byte-identical to the public Weave example and the repository license.
